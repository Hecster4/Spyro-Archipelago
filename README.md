# Spyro-Archipelago
An Archipelago apworld and client for Spyro the Dragon on the Duckstation Emulator

## Checks

* Every 100 Gems in each level
* 100% Completion of each level
* All Dragons
* All Eggs

## Randomized Items

* 100 Gems
* Dragons
* Eggs
* Portal Unlocks (if enabled)

## Options

* Deathlink
* Portal Unlocks

## Goal

Currently the only goal is to defeat Gnasty Gnorc but I am planning to add more goals in the future. Requirements to progress to hub worlds remain the same and you must obtain the relevant items. If portal locked are enabled then you must obtain the relevant portal unlock item.

## Required Software

* [Archipelago Launcher](https://github.com/ArchipelagoMW/Archipelago/tree/main)
* [Duckstaion Emulator](https://github.com/stenzek/duckstation/tree/82a11824976bb9afe1d5d433025aa6ccf99e89be)
* Spyro the Dragon.cue/bin SCUS-94228(USA)

## Installation

1. Download and install the latest release of Archipelago Laucher
2. Download and install the latest release of Duckstaion Emulator
3. Download and intsall the latest release of Spyro the Dragon apworld

## Setup

1. Move Spyro the Dragon.cue/bin into Duckstation games folder
2. Open Duckstaion and go to Settings/Advanced and enable Show Debug Menu
3. In Duckstation go to settings/Console and set Execution Mode to Interpreter
4. In Duckstation go to Settings/Debugging and enable Export Shared Memory
5. Start Spyro the Dragon and load into a new save
6. Open the Archipelago Launcher and open the Spyro Client
7. Connect to server by inputting Archipelgo server address
8. Input password if required and input slot name
9. Enjoy playing
